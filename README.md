# StepSound-Speaker
StepSound is an experimental electronics project exploring whether a stepper motor can be used to produce musical notes and melodies, inspired by the sounds made by Bambu Lab 3D printers.

# Hardware:
 Microcontroller: ESP32 development board
 Motor: 28BYJ-48 stepper motor
 Motor driver: ULN2003 driver board
 Power: Suitable regulated supply for the motor
# Software: 
 Arduino IDE
